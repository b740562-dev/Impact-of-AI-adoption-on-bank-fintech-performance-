# Spec changes

Changes to the fixed spec in CLAUDE.md. Each entry: date, section, change, reason. Logged **before** re-running.

| Date | Section | Change | Reason |
|---|---|---|---|
| 2026-11-26 | §4 controls (`pca`) | PCA sources: exits from RBI press releases. Entries from the bank's own BSE/NSE filing quoting RBI's letter (primary source); the set is cross-checked against the PIB release of March 2018. If no entry filing is found, entry = "on or before" the PIB release date, with `entry_inferred` = 1 (logged). Coding: `pca` = 1 for a bank-FY if the bank was under PCA for at least 6 months of that FY (Apr–Mar), else 0; `pca_months` (0–12) saved. Enters lagged one year. Only panel banks are coded (BOI, BOM, UCO, IOB, Central); merged-away PCA banks are outside the panel. | RBI issues press releases only for PCA exits, not entries (none found), so the earlier "RBI press releases only" rule cannot date entries. Researcher's decision; no estimates run with `pca`. |
| 2026-11-25 | §4 proxy 5 (citation) | Fintech index weighting confirmed: equal weight 1/6 per item (scaled mobile-banking volume + 5 feature dummies), binary and scaled-continuous items treated alike. | Follows Hamdouni (2025), *International Journal of Financial Studies* 13(4):234 (Variables Selection sheet): equal-weighted sum across individual indicators. |
| 2026-11-25 | §4 `ai_kw` (numerator/denominator) | English-vocabulary filter applies to the **denominator only**; AI dictionary terms (AI, ML, NLP, RPA, GenAI, LLM are not dictionary words) are counted on the raw extracted text. The vocabulary gets a banking-jargon whitelist (CASA, NPA, GNPA, CRAR, MSME, RBI, UPI, KYC, NIM, SLR, CRR, NBFC, PSB, and bank/product names). Report per annual report the share of Latin-script tokens dropped. Sanity check: English-only reports should drop <15%; any report dropping >40% is flagged for manual check; distribution printed by bank type. | Researcher's decision (2026-11-25): makes the denominator filter transparent and stops it from removing legitimate banking terms. No estimates run yet. |
| 2026-11-25 | §5 Phase 1 | Each Phase 1 OLS is also reported without the crisis dummies, side by side with the version that includes them. | Researcher's decision; shows sensitivity of ~15-observation regressions to the dummies. No estimates run yet. |
| 2026-11-25 | §2, §5 Phase 1 | Phase 1 has three levels: (a) whole sector = panel PSU + private banks combined, (b) private banks, (c) PSU banks. Outcomes (ROE, ROA, GNPA) from RBI group aggregates (sector = PSU + private aggregates summed before computing ratios). AI intensity = total-assets-weighted average of `ai_kw` over the panel banks in that level. Per level: trend chart (`ai_kw` vs ROE, ROA, GNPA, FY2011–FY2025), mean comparison pre-FY2017 (FY2011–16) vs post (FY2017–25), and OLS of ROE_t on `ai_kw`_(t−1) + GDP growth + crisis dummies (demonetisation FY2017, AQR FY2016–18, COVID FY2021). Descriptive evidence only. | Researcher's design decision (2026-11-25). Made before any Phase 1 estimate was run. |
| 2026-11-25 | §4 proxy 5 | `digital_idx` replaced by the **Fintech index** `fintech_idx` (Variables Selection sheet): equal-weighted average of (a) bank-wise mobile-banking transaction volume from RBI, min–max scaled 0–1 over all bank-FYs, and (b) feature dummies — mobile app, UPI live, chatbot, voice assistant, video-KYC — each = 1 from the FY the feature went live. Six items, weight 1/6 each. Report year coverage; NA where the RBI volume is missing. | Researcher's decision, aligning proxy 5 with the Variables Selection sheet. No estimates run with `digital_idx`. |
| 2026-11-25 | §4 `ai_kw` | Main `ai_kw` = rate per 10,000 English words. English words = Latin-script tokens that pass the English-vocabulary filter (entry below), because legacy-font Hindi also extracts as Latin script. Robustness: `ai_kw_ln` = ln(1 + raw AI-term count). | Researcher's decision; `ai_kw_ln` matches the source paper in the Variables Selection sheet. No estimates run yet. |
| 2026-11-25 | §4 controls | New control `pca` = 1 in bank-FYs under RBI Prompt Corrective Action (lagged one year like the other controls). Entry and exit dates are built only from RBI press releases, with source URLs recorded in docs/data_notes.md. Nothing is hardcoded from memory. | Researcher's decision; PCA restrictions directly constrain lending and expansion of affected PSU banks. No estimates run yet. |
| 2026-11-25 | §4 moderators, §5 Phase 2a | New moderator: baseline Z-score per bank = (mean ROA + mean equity/assets) / SD(ROA), all over FY2011–FY2015, standardised across banks. AI × Z is added to the FE heterogeneity set. Banks without FY2011–15 data (IDFC First) get NA and drop out of this interaction. | Researcher's decision (baseline risk as moderator). No estimates run yet. |
| 2026-11-25 | §4 controls / moderators, §5 Phase 2b | Firm age enters only as baseline age (FY2011) × AI and as a DiD covariate (`xformla`). Profit growth is robustness only. Both restate and tighten the existing spec. | Researcher's clarification. No estimates run yet. |
| 2026-11-25 | §4 `ai_kw` dictionary | Acronyms LLM/LLMs, NLP and RPA are matched case-sensitively (uppercase as written, "LLMS" all-caps excluded) and only where the ±60-character window contains ordinary lowercase text; "LLM" in law-degree context (LLB/LL.M/Master of Law) is excluded. Full-phrase terms stay case-insensitive. | Audit of matches before any results: "LLMS" = Loan Lifecycle Management System (BoM, SBI, Central), "LLM" = directors' law degree, and legacy-font Hindi (Kruti Dev–style) renders as Latin gibberish producing isolated "LLM"/"Rpa"/"llm" tokens (e.g. PNB FY2015: 100 false "LLM"). Implements the spec's "exclude false positives". |
| 2026-11-25 | §4 `ai_kw` denominator | "Total words" = English words only: tokens that occur in at least 3 different private-bank annual reports (English-only reports). Raw token count is also stored. | Bilingual PSU reports set in legacy Hindi fonts extract as Latin gibberish, which inflated the word count of PSU reports and would bias PSU `ai_kw` downward. |
| 2026-11-25 | §2, §3b, §4 (sample period) | Accounting outcomes (ROE, ROA, controls) end FY2025 because RBI FY2026 tables are not yet published; stock returns run to FY2026. | RBI *Statistical Tables Relating to Banks in India* on DBIE covers FY2005–FY2025 as of 2026-11-25; the 2025-26 edition is not yet released. |
