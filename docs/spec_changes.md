| 2026-11-26 | §5 Phase 2a heterogeneity (**post-hoc**) | Added: AI~×~PSU (lag 1, all four outcomes) re-estimated with (a) PSU-specific year fixed effects (bank FE + PSU×FY FE) and (b) bank-specific linear trends (bank FE + bank×FY slope + FY FE), next to the original specification; the implied PSU slope (AI + AI×PSU) is reported with its clustered SE. | 2026-11-26 | §4 proxy 3 (replaced) | AI patents dropped as a proxy: Indian banks file almost no AI patents (share of zero bank-years: AI patent applications 400 of 400 = 100%; any patent filing 399 of 400 = 99.75%, the one filing being SBI's IN202121002961A in FY2021). Kept as a descriptive fact only. Replaced by `ai_capability` (closest available measure of "innovative capability" from the Variables Selection sheet, which lacks R&D/tech-staff data): sum (0–4) of four binary components per bank × FY, each 1 if that FY's annual report mentions it, else 0, coded as observed per report (no carry-forward): (1) `cap_lead` dedicated digital/data/AI leader (Chief Digital / Data / Analytics / AI Officer; Head of AI / Analytics / Data Science; CIO, CTO, CISO excluded); (2) `cap_lab` AI / analytics / data / innovation lab or centre of excellence; (3) `cap_committee` board or management committee specifically for digital / AI / data / innovation (IT Strategy Committee and risk/audit committees excluded); (4) `cap_team` in-house data science / AI / ML / analytics team. Text matching on the already-extracted annual-report text (`src/python/13_ai_capability.py`); bank-FYs without a report are NA. Used in place of `ai_patents` in the robustness table (per 1 SD, lagged one year). | Researcher's decision (2026-11-26) after the pre-specified patent search returned no variation; no estimates run with `ai_capability` yet. |
| 2026-11-26 | §4 proxy 3 (`ai_patents`) | Dropped from estimation (§0 fallback: proxy source fails). The pre-specified search was run (Google Patents Public Data on BigQuery, all 25 panel banks by harmonised assignee, filings from 2009-04-01, CPC G06N or dictionary terms): it returns 1 publication in total (SBI, IN202121002961A, 2021, no title/abstract/CPC) and 0 AI applications, so `ai_patents` = 0 for every bank-FY and has no variation. The zeros stay in the panel (`n_ai_patent_apps`, `ai_patents`); `40_robustness.R` skips proxies with zero variance. | Data limitation, not a result-driven choice: Google Patents' web search also shows 1 SBI result and none for ICICI Bank since 2009, so the source has almost no Indian-bank filings. The Indian Patent Office search requires a CAPTCHA and cannot be scripted. Decided before any estimate with this proxy. |

Labelled as post-hoc in all outputs. |
| 2026-11-26 | §4 proxy 5 (`fintech_idx`) operational details | (a) Mobile-banking volume from RBI monthly "Bank-wise Mobile Banking Transactions" releases (rbi.org.in NEFTUserView pages); FY volume = mean monthly volume × 12 when ≥ 6 months are available, else NA. (b) Feature go-live FY = first FY in which the bank's annual report mentions the feature (mobile app, UPI, chatbot/virtual assistant, voice assistant/Alexa/Google Assistant, video-KYC/V-CIP), absorbing thereafter; 0 before. | Exact go-live dates for 25 banks × 5 features are not available from a single source; annual-report first mention is consistent across banks and scripted. Caveat: a mention can precede or follow go-live by up to a year. Decided before computing the index. |
| 2026-11-26 | §4 controls (`pca`) | PCA sources: exits from RBI press releases. Entries from the bank's own BSE/NSE filing quoting RBI's letter (primary source); the set is cross-checked against the PIB release of March 2018. If no entry filing is found, entry = "on or before" the PIB release date, with `entry_inferred` = 1 (logged). Coding: `pca` = 1 for a bank-FY if the bank was under PCA for at least 6 months of that FY (Apr–Mar), else 0; `pca_months` (0–12) saved. Enters lagged one year. Only panel banks are coded (BOI, BOM, UCO, IOB, Central); merged-away PCA banks are outside the panel. | RBI issues press releases only for PCA exits, not entries (none found), so the earlier "RBI press releases only" rule cannot date entries. Researcher's decision; no estimates run with `pca`. |
| 2026-11-25 | §4 proxy 5 (citation) | Fintech index weighting confirmed: equal weight 1/6 per item (scaled mobile-banking volume + 5 feature dummies), binary and scaled-continuous items treated alike. | Follows Hamdouni (2025), *International Journal of Financial Studies* 13(4):234 (Variables Selection sheet): equal-weighted sum across individual indicators. |
| 2026-11-25 | §4 `ai_kw` (numerator/denominator) | English-vocabulary filter applies to the **denominator only**; AI dictionary terms (AI, ML, NLP, RPA, GenAI, LLM are not dictionary words) are counted on the raw extracted text. Sanity check: English-only reports should drop <15%; any report dropping >40% is flagged for manual check; distribution printed by bank type. | Researcher's decision (2026-11-25): makes the denominator filter transparent and stops it from removing legitimate banking terms.
